# Human-demo observation adapter V2 evidence

This directory is the authoritative evidence package for the separate masked observation adapter.
See `docs/RIVAL2_HUMAN_DEMO_OBSERVATION_ADAPTER_V2.md` for the frozen architecture, objective,
quality semantics, exact full-observation bypass, native boost-pad boundary, validation gates, and
commands.

`frozen_config.json` is committed and pushed before the first adapter optimizer step. Generated
run artifacts are added only after the bounded adapter-only run finishes. V1 failure evidence is
not copied, edited, superseded, or reinterpreted here.
