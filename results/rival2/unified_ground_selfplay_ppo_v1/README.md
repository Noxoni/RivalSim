# Unified Ground Self-Play PPO V1

This campaign is the first corrective PPO stage after the Unified V5 capability
claim audit. It does not claim that the source naturally performs named
mechanics. It trains both current-policy perspectives in native 120 Hz 1v1
self-play using the already validated Gameplay 120 V2 physical reward.

The supplied competency checklist is treated as an eventual behavioral
evaluation taxonomy, not as forty-five independent shaped rewards. This stage
directly emphasizes goals, signed goalward progress, velocity-matched close
control, saves, boost-pad pickup, authoritative supersonic movement, and the
existing targeted unnecessary flip-through penalty. Useful shooting,
possession, challenges, and 50 outcomes therefore improve through their actual
competitive consequences.

The policy remains stochastic during PPO, as required by the policy-gradient
estimator, but uses a deliberately conservative exploration range. KL is
telemetry only; it never rejects or rolls back an otherwise finite update.
Nonfinite loss, gradient, or parameters still fail closed with transactional
rollback.
